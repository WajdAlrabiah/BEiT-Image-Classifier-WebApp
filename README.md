# BEiT Image Classifier WebApp

A lightweight Flask web application for performing **image classification** using the **BEiT** model from the Hugging Face Transformers library.  
Users can upload an image through the browser, and the app will display the predicted class with confidence.

---

## Features
- Web interface built with **Flask**
- Uses **BEiT (microsoft/beit-base-patch16-224-pt22k-ft22k)** for classification  
- Real-time image prediction
- Displays class name and probability
- Easy to run locally or in Google Colab

---

## Model Used
- **Model:** `microsoft/beit-base-patch16-224-pt22k-ft22k`
- **Frameworks:** PyTorch & Hugging Face Transformers
